# 01 产品需求文档

## 用户与场景

面向需要在 ROS2 环境中开发、演示或验证 Tello 人体跟踪系统的机器人开发者。系统同时支持真实 Tello 和本地 Mock，使用离线视频复现视觉链路。

## 功能需求

- FR-01：管理 Tello 命令、状态和视频三个 UDP 通道。
- FR-02：解析遥测并持续发布链路健康度。
- FR-03：检测人体、分配跟踪 ID、锁定/解除目标并发布标注图像。
- FR-04：使用具有 `dt`、限幅、死区和滤波的 PID 生成控制建议。
- FR-05：通过状态机批准起飞、跟踪、降落和急停。
- FR-06：电量不足、状态/视频超时、目标丢失和控制过期时进入安全状态。
- FR-07：支持 Mock Tello、离线视频和 rosbag 回放。
- FR-08：所有关键阈值、路径、速率和设备可配置。

## 非功能需求

- 控制循环默认 20 Hz，控制建议过期时间默认 0.5 秒。
- 命令默认 2 秒超时、最多 3 次尝试。
- 图像使用深度 1 的 Sensor Data QoS，只处理最新帧。
- 新环境能够依据 README 完成构建和启动。
- 连续离线回放一小时无崩溃和持续内存增长。

## 范围边界

本版本不实现 TensorRT、ESP32 固件、Device Tree、GPIO/SPI 内核驱动或 CSI Camera 适配，但公共接口不得阻碍后续加入这些模块。
