# 08 硬件测试信息

本文件是硬件测试的唯一状态与证据入口。当前表格中的用例均为待硬件验证，不得将“预期结果”当作“实测结果”。

## 测试设备与安全准备

- Tello 或 Tello EDU、已充电电池、备用电池和原厂充电器；
- Ubuntu 22.04 / ROS2 Humble 控制端，后续 Jetson 测试使用对应开发套件；
- 开阔、无人员穿行、无易碎物的飞行区域和安全观察员；
- 首轮控制测试拆除螺旋桨，确认 RC 方向、急停和降落策略后再装桨；
- 检查 Wi-Fi 信号、电池、电机、桨叶、防护罩和紧急人工接管流程；
- 每次用例保存时间、配置 SHA、ROS 日志、rosbag、视频及操作者结论。
