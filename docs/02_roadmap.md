# 02 版本规划

| 版本 | 状态 | 内容 |
| --- | --- | --- |
| 0.1.0 | 当前 | 仓库治理、自研 UDP、状态机、Mock、离线回放和测试基线 |
| 0.2.0-prep | 完成 | Jetson 基线、ONNX/TensorRT 工具、性能基准和 systemd 部署预研 |
| 0.2.0 | 进行中 | Jetson 配置、GStreamer 硬件解码、系统诊断、原生部署与 TensorRT FP16 验收 |
| 0.3.0 | 规划 | ESP32-S3 UART 安全板、CRC16、心跳和物理输入 |
| 0.4.0 | 规划 | Device Tree Overlay、GPIO Platform Driver、SPI/IIO |

每个版本只有在代码、自动化测试、验收记录和运行文档同步后才可关闭。
