## 接线前强制检查

- Jetson 与 ESP32 直连时必须共地，UART 与 SPI 信号统一为 3.3V。
- GPIO 接线前核对 Jetson 40Pin 定义、Pinmux、最大电压和最大电流。
- 急停板只能触发软件层安全动作，不能描述为切断 Tello 动力的硬回路。
- 逻辑分析仪只接数字信号，不用于电源负载或高压测量。
- 首批核心新增预算按原方案预留约 ¥2,400～4,500，不含已有 Tello、电池和通用显示设备。
